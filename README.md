# 🍔 Bite & Bun

Website đặt đồ ăn nhanh (F&B) cho thương hiệu **Bite & Bun** tại TP.HCM — đồ án tốt nghiệp ngành Thiết kế UI/UX. Giao diện thiết kế trên **Figma**, dựng thành web thật bằng **React + Tailwind CSS**, có **backend thật trên Supabase**.

## ✨ Tính năng chính
- **Trang chủ**: hero, flash deals, món bán chạy, danh mục, khu đặt bàn.
- **Thực đơn**: lọc theo nhóm, tìm kiếm, sắp xếp; dữ liệu lấy từ Supabase.
- **Giỏ hàng & thanh toán**: mã giảm giá, giao hàng/đến lấy, xác thực OTP demo.
- **Đơn hàng thật**: lưu lên Supabase, theo dõi & xem lịch sử.
- **Đăng nhập/đăng ký thật**: Supabase Auth, nhớ phiên khi tải lại.
- **Rewards**: tích điểm "Bun", 3 hạng thành viên, ví voucher.
- **Đặt bàn** theo chi nhánh: lưu & tra cứu trên Supabase.
- **Trợ lý AI**: hỏi đáp về quán (API key giấu an toàn ở máy chủ).
- Chế độ Sáng/Tối, giao siêu tốc, tìm nhanh, yêu thích.

## 🛠️ Công nghệ
- **Giao diện**: React 18, TypeScript, Tailwind CSS
- **Thiết kế**: Figma → Figma Make
- **Backend**: Supabase Edge Functions (Deno + Hono), Supabase Auth
- **AI**: Google Gemini (gọi qua máy chủ để giấu key)

## 🚀 Chạy ở máy
\`\`\`bash
npm install
npm run dev
\`\`\`
Mở trình duyệt vào địa chỉ terminal in ra (thường `http://localhost:5173`).
